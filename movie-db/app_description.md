Simple application that presents a list of movies. Every movie has title, release date, director name, genres assigned. The application should use Angular Material and be styled with mobile first approach. There should be standard angular material top header. There should be filters at the top that allow to filter movies by title, release date and genre. The app should be nicely looking but not too complex. The application should use state of the art reactive state management with rxjs. Create separate services for API interaction and separate services for state management. The API service should mock the data returned from the server instead of calling the actual API. Ass some fake delay to the API services to simulate backend processing. The movies should be stored in a JSON file. Use state of the art approach of applying rxjs operators. The filters change should cancel the previous requests and be debounced so that every search keystroke do not trigger the call to api immidiately. If there are no results appropriate no results content should be displayed. Correct components from the Angular material should be sued. When the list of movies loads the loader should be presented.
